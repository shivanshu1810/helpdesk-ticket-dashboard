# Helpdesk Ticket Dashboard

A small ticket dashboard I made in Python to practice. It uses only Python itself, so there is nothing to install.

## What it does

- Shows how many tickets are open, in progress, resolved and closed
- Shows tickets by priority
- Lists all the tickets
- Has a form to add a new ticket
- Starts with 6 made up sample tickets so it works right away

Tickets are saved in a SQLite file called tickets.db. The file is made the first time you run the app.

## How to run

    python app.py

Then open http://localhost:8000 in your browser.

I made this to understand how a service desk dashboard works, because I used one every day at my co-op job.
